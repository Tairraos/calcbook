# 计算语言契约

状态：有效 · 负责人：项目维护者 · 核验日期：2026-09-07

[可执行验收数据](../../tests/cases/calculations.json) 是本契约的回归例子。修改语义时同时修改契约和用例，不能只让 UI 看起来正确。

## 行与作用域

- 每行独立解析，变量依行序求值；每次编辑重新计算整篇笔记。
- 空行重置汇总段落；`#` 开头为标题，`//` 为注释。行内 `//` 后的内容也不计算。
- `说明: 算式` 或 `说明：算式` 中只计算冒号后的部分。
- 普通文字保留为笔记。以数字或运算符开头、包含算术运算、赋值、函数调用或已知变量的行作为算式处理。为了避免文字被误判，数字开头的说明应使用 `//`。
- 变量名支持 Unicode 字母、数字和下划线，不能以数字开头；常量、单位、函数、汇总名和语法关键字为保留名。
- 变量仅可引用前文；重定义失败会删去该变量的旧值。作用域不跨笔记，不执行用户函数或脚本。

## 支持语法

| 输入 | 结果/规则 |
| --- | --- |
| `0.1 + 0.2` | `0.3`，内部十进制 64 位有效数字 |
| `(18 + 24) × 3` | `126`；也支持 `* / ÷ - + ^` |
| `2x3x4`、`(2+3)x4` | `24`、`20`；数字或括号之间的 x 可不加空格 |
| `价格 x 数量` | 变量之间的 x 两侧加空格；`tax`、`x2` 等变量名保持完整 |
| `x=4` 后 `2*x` | `8`；x 仍可作为变量，引用时使用明确的乘号 |
| `{[18+24] x (3-1)}` | `84`；三种括号作为同等的分组符号，可嵌套混用，不表示数组/对象 |
| `2^3^2`、`-2^2` | `512`、`-4`，遵守数学优先级 |
| `6(3)` | `18`，隐式乘法 |
| `8 times 9` | `72`；支持 plus/minus/times/divided by |
| `价格 = 128` 后 `价格 × 3` | `384` |
| `200 + 10%` / `200 - 10%` | `220` / `180`，右侧直接百分比相对左值 |
| `20% of 150` | `30`；`10% on 200` 为 220，off 为 180 |
| `折扣 = 10%` 后 `200 - 折扣` | `180`；直接百分比变量保留相对百分比语义 |
| `12%` | 显示十进制比率 `0.12`；计算器与笔记一致 |
| `5 km to m` | `5000 m`；in/into/as 也可作为转换词 |
| `2 km + 500 m` | `2.5 km` |
| `90 min to hour` | `1.5 hour`；min 映射为 minute 避免函数名冲突 |
| `5 公里 to 米` | `5000 m`；常用中文长度/质量/时长别名 |
| `¥30 + 12 CNY` | `42 CNY`；$、€、£ 分别为 USD/EUR/GBP |
| `sqrt(144)` / `abs(-5)` | `12` / `5` |
| `round(2.345,2)` / `ceil(2.1)` / `floor(2.9)` | `2.35` / `3` / `2` |
| `prev + 4` | 使用前一个成功结果；标题、注释、空行不清除 prev，错误会清除 |

百分比在括号、复合表达式中的规则遵循 mathjs；不是把所有十进制比率都自动当作折扣。直接百分比变量复制为十进制值时不携带变量元信息。

## 显示精度与继续计算

笔记的结果与复制值最多 14 位有效数字，后续依赖行继续使用内部 64 位十进制精度。普通计算器采用独立显示规则：

- 最多保留小数点后三位，四舍五入并去掉末尾零；`1/3` 显示 `0.333`，`2/3` 显示 `0.667`，极小负值舍入后显示 `0`。
- 常规显示上限是十位整数加三位小数；`9999999999.999` 显示 `9,999,999,999.999`。舍入后达到十一位整数时改为科学计数法，尾数最多三位小数，例如 `12345678901` 显示 `1.235e+10`。
- 根据结果区实际宽度缩小字号，完整显示数值，不出现横向滚动条。负号与千位分隔符也包含在适配范围内。
- 计算器历史与续算保留 64 位精度的原值；`1 ÷ 7 =` 显示 `0.143`，再 `× 7 =` 显示 `1`。插入笔记使用源算式，避免把三位小数当成真实值。

## 汇总

`sum` / `total` / `合计`：汇总本段此前成功计算行。`avg` / `average` / `平均`：算术平均。标题和注释不进入汇总；空行开始新段。汇总行不再次计入本段，避免 sum 后 avg 重复计算总数。

赋值行也是计算行，会计入汇总；已有小计应以空行分段。单位不兼容或本段含错误时汇总显示错误，不给出悄悄漏项的总数。空段汇总显示错误。

## 失败与资源边界

除零、NaN、未知符号、非法节点、单位冲突都返回行级错误，其他独立行继续计算。没有跨币种汇率；不同币种转换必须报错。

单行表达式最多 1000 字符、160 个 AST 节点、32 层，指数绝对值最多 1000，结果绝对值不超过 1e308。只接受数字与单位结果；数组、矩阵、属性访问、赋值节点、导入、用户函数等均在执行前拒绝。
