# 计算语言契约

状态：有效 · 负责人：项目维护者 · 核验日期：2026-09-07

[可执行验收数据](../../tests/cases/calculations.json) 是本契约的回归例子。修改语义时同时修改契约和用例，不能只让 UI 看起来正确。

## 行与作用域

- 每行独立解析，变量依行序求值；每次编辑重新计算整篇笔记。
- 空行重置汇总段落；`#` 开头为小节标题（仅内容标记，与笔记文件名/标题无关），`//` 为注释。行内 `//` 后的内容也不计算。
- `说明: 算式` 或 `说明：算式` 中只计算冒号后的部分；冒号前是纯数字时整行视为比率算式（如 `16:9`），不剥离标签。
- 普通文字保留为笔记。以数字或运算符开头、包含算术运算、赋值、函数调用或已知变量的行作为算式处理。为了避免文字被误判，数字开头的说明应使用 `//`。
- 变量名支持 Unicode 字母、数字和下划线，不能以数字开头；常量、单位、函数、汇总名和语法关键字为保留名。等号左边使用保留字时该行出错，错误信息以「保留字冲突」开头并指明类别（单位名/函数名/常量名/汇总关键字/单位转换关键字），如 `月 = 12` → `保留字冲突："月"是单位名，请换一个变量名`。
- 变量仅可引用前文；重定义失败会删去该变量的旧值。作用域不跨笔记，不执行用户函数或脚本。

## 支持语法

| 输入 | 结果/规则 |
| --- | --- |
| `0.1 + 0.2` | `0.3`，内部十进制 64 位有效数字 |
| `(18 + 24) × 3` | `126`；也支持 `* / ÷ - + ^` |
| `16:9` | `1.7778`；两个数字之间的 `:`/`：` 是比率，等价除法。冒号前是数字才当比率，文字冒号仍是「说明: 算式」的标签分隔符 |
| `2x3x4`、`(2+3)x4` | `24`、`20`；数字或括号之间的 x 可不加空格 |
| `价格 x 数量` | 变量之间的 x 两侧加空格；`tax`、`x2` 等变量名保持完整 |
| `x=4` 后 `2*x` | `8`；x 仍可作为变量，引用时使用明确的乘号 |
| `{[18+24] x (3-1)}` | `84`；三种括号作为同等的分组符号，可嵌套混用，不表示数组/对象。嵌套最多 3 层，超出报「括号嵌套层数越限」（1.6.12 起）；嵌套形态固定为 `{[( )]}`——最内层 `()`，向外 `[]`、`{}`（格式化按此收敛，1.6.12 起） |
| `2^3^2`、`-2^2` | `512`、`-4`，遵守数学优先级 |
| `6(3)` | `18`，隐式乘法 |
| `8 times 9` | `72`；支持 plus/minus/times/divided by |
| `价格 = 128` 后 `价格 × 3` | `384` |
| `200 + 10%` / `200 - 10%` | `220` / `180`，右侧直接百分比相对左值 |
| `20% of 150` | `30`；`10% on 200` 为 220，off 为 180 |
| `折扣 = 10%` 后 `200 - 折扣` | `180`；直接百分比变量保留相对百分比语义 |
| `12%` | 显示十进制比率 `0.12`；计算器与笔记一致 |
| `5 km to m` | `5000 m`；in/into/as 也可作为转换词 |
| `2 km + 500 m` | `2.5 km` |
| `90 min to hour` | `1.5 hour`；min 映射为 minute 避免函数名冲突 |
| `5 公里 to 米` | `5000 m`；常用中文长度/质量/时长别名 |
| `1 mile + 1 km` | `2.6093 km`；公制英制混算时英制并入公制，结果以公制呈现 |
| `1 lb + 1 kg` | `1.4536 kg`；纯英制算式（如 `1 mile + 1 ft`）保持英制不变 |
| `1500毫克` | `1,500 mg`；结果保留用户写下的单位与前缀，不做自动换档（换档用显式 `to`） |
| `1英里 + 1公里` | `2.6093 km`；英制也有中文名（英寸/英尺/码/英里/磅/盎司/加仑/品脱/夸脱/杯/汤匙/茶匙/英亩/华氏度/马力/psi/英热单位/节等） |
| `¥30 + 12 CNY` | `42 CNY`；$、€、£ 分别为 USD/EUR/GBP |
| `sqrt(144)` / `abs(-5)` | `12` / `5` |
| `round(2.345,2)` / `ceil(2.1)` / `floor(2.9)` | `2.35` / `3` / `2` |
| `prev + 4` | 使用前一个成功结果；标题、注释、空行不清除 prev，错误会清除 |

百分比在括号、复合表达式中的规则遵循 mathjs；不是把所有十进制比率都自动当作折扣。直接百分比变量复制为十进制值时不携带变量元信息。

## 单位系统

单位名在 `src/domain/units.ts` 中逐条登记（英文规范名 + 中文规范名 + 其他写法）。登记后才可作为单位解析；变量名与单位名冲突时单位优先（保留名）。

- **覆盖范围**：长度（含英寸/英尺/码/英里/海里）、面积（含英亩/亩）、体积（含加仑/品脱/夸脱/杯/汤匙/茶匙）、质量（含磅/盎司/英石/斤/两）、时间、温度、速度（km/h、mph、节）、能量（含卡/千卡/千瓦时/英热单位）、功率（含马力）、力、压强、频率、电学、数据、货币。
- **结果单位规则**：制式优先级为 公制 > 英制 > 市制——同行出现更高优先级制式时，结果换算到该制式；同制式内向**更小的单位**靠拢（`5ml+6L` → `6,005 ML`、`1L+500ML` → `1,500 ML`、`2 km + 500 m` → `2,500 m`、`1 mile + 1 ft` → `5,281 foot`）。结果单位语言跟随算式：中文 > 大写英文 > 小写英文（`1英里 + 1公里` → `2.6093公里`）。显式 `to` 指定的目标单位始终原样呈现。
- **同量纲约分**：同量纲分量在结果中互相抵消——全部抵消时退回纯数字（`10.2克 / 100克` → `0.102`、`1 m / 1 cm` → `100`），部分抵消时合并（`体重 / (身高/米)^2` → `22.3435 kg`）。
- **显示保留**：结果保留该行第一个操作数写下的单位与前缀（`1500mg` → `1,500 mg`）；需要换档或换算时用显式 `to`。乘除得到的复合单位不再自动简写成其他单位（如 `kg·m/s²` 不自动变 N），需要时写 `to N`。
- **单位模式**（设置页三选一，存入工作区）：
  - `自由单位`（默认）：整篇可混用单位。光标离开刚算完的行时，只有该行同时出现中英文单位才统一改写成中文。
  - `中文单位` / `英文单位`：光标离开刚算完的行时，把该行算式（不含标签与 `//` 注释）里的单位改写成对应语言，如 `100L` → `100升`、`4毫升` → `4 ml`。改写只处理当前这一行，不重排整篇。
- 已知边界：Numi 把未知词当单位（`240片`），Calcbook 视为未定义符号报错；`in` 是转换词，英寸请写 `inch` 或 `英寸`；复合单位的幂用 `^` 写（`1 m/s^2` → `1 m / second^2`），`m/s2` 中的 `s2` 是未知符号。

## 显示精度与继续计算

笔记与计算器的结果最多保留小数点后 4 位（四舍五入、去掉末尾零），后续依赖行继续使用内部 64 位十进制精度，不受显示舍入影响。复制值（Shift+C 或点击结果）保留 14 位有效数字，供精确取用。

- **数字宽度上限（1.6.10 起）**：整数部分最长 16 位、小数部分最长 4 位——笔记里的输入数字与计算器输入的数字都受此限制，结果按 4 位小数舍入后整数部分超过 16 位同样不显示。超出不计算，报错分两类：**写下的数字**超宽报「数字宽度超限」（`12345678901234567`、`0.12345`），**计算得到的**结果超宽报「计算结果数字宽度超限」（`9999999999999999 + 1`、`2^60`，1.6.11 起区分文案）；计算器在输入时就封顶——整数到 16 位、小数到 4 位后继续按数字无反应（1.6.11 起），不用科学计数法。`9999999999.9994` 显示 `9,999,999,999.9994`，`12345678901` 显示 `12,345,678,901`，`9999999999999999` 是上限；极小值舍入后显示 `0`。
- 根据结果区实际宽度缩小字号，完整显示数值，不出现横向滚动条。负号与千位分隔符也包含在适配范围内。
- 笔记的续行与复制值仍使用内部 64 位精度（见上）。计算器子窗口自 1.5.5 起整体工作在显示精度上：等号后算式框与结果列同时变成显示值，续算、退格与「最近计算」复用都在四位显示值上进行——`1 ÷ 7 =` 显示 `0.1429`，再 `× 7 =` 得 `1.0003`。算式框、续算基值与历史条目是不带千分位逗号的同值（1.6.14 起），±、退格与宽度检查都按纯数字处理；结果大字仍带千分位。历史条目保留源算式，「插入笔记」仍发送源算式，避免把四位小数写进笔记。

## 全文格式化

设置弹窗「格式」区配置书写规范，顶栏「格式化」按设置整理当前笔记的全部行（默认不自动格式化）：

- 可设置项：数字千分位逗号（默认否）、数字和单位之间空格（默认否）、数字和百分号之间空格（默认否）、运算符（`+ - * / =`）两边空格（默认要）、注释符号后空格（默认要）、单位使用（自由/中文/英文大写/英文小写，默认自由）、单位制（自由/公制/英制/市制，默认自由）。
- 强制规则（不可配置）：操作符词（of/to/in/on/off/into/as/plus/minus/times）两边必须空格；函数（sqrt/abs/round/ceil/floor）前必须空格；括号和数字之间不留空格；标签统一英文冒号加单空格。
- 强制规则：乘号统一写成 `×`——`x`（按引擎判定为乘法时，与 `2 x 3`、`2x3` 的求值语义一致）与 `*` 都在排版前替换为 `×`。除号不替换：`÷` 与 `/` 保持原样，`/` 可继续用来表达分子/分母。
- 单位制非自由时，一行内按 公制 > 英制 > 市制 把数字+单位换算成目标制式（显式 `to` 的行保持原样）。
- 单位使用为中文/大写/小写时，改写算式里的单位写法；自由模式保留原文。
- 中文写法优先级（1.6.1）：公斤 → 千克、公分 → 厘米——格式化把算式里这两种别名写法收敛到规范中文名（注释不参与，实时结果仍保留用户写法；其余中文别名如公尺、千米、焦耳不受影响）。
- 乘号的判定与引擎共用同一条规则：只有写成 `x` 且左右是操作数时才当作乘法改写（`票价 x 人数` → `票价 × 人数`），变量名里的 `x`（`x = 5`、`max`）和单独的 `x` 不受影响；格式化前后的求值结果必须逐行一致。
- 强制规则：连续空格收敛为单空格、行尾无空格、`#` 与 `//` 都可用作整行注释/标题与尾部注释（`#` 前不需要空格，`预算=交通+3#备注` 的 `#备注` 即尾部注释）；标签一律归一为英文冒号加单空格（`备用金：每人 × 10%` → `备用金: 每人 × 10%`）。
- 强制规则（1.6.12 起）：括号字形按嵌套层级收敛——最内层 `()`，向外 `[]`、`{}`，即 `{[( )]}`；`([18+24] x (3-1))` 格式化为 `[(18 + 24) × (3 - 1)]`。换形只是字形替换，求值结果逐行不变（三种括号求值前统一为圆括号）。
- 撤销：格式化后 Cmd/Ctrl+Z 可整篇还原（应用内撤销），用户继续编辑后该撤销作废。

## 汇总

`sum` / `total` / `合计`：汇总本段此前成功计算行。`avg` / `average` / `平均`：算术平均。标题和注释不进入汇总；空行开始新段。汇总行不再次计入本段，避免 sum 后 avg 重复计算总数。

赋值行也是计算行，会计入汇总；已有小计应以空行分段。单位不兼容或本段含错误时汇总显示错误，不给出悄悄漏项的总数。空段汇总显示错误。

## 失败与资源边界

除零、NaN、未知符号、非法节点、单位冲突都返回行级错误，其他独立行继续计算。没有跨币种汇率；不同币种转换必须报错。

单行表达式最多 1000 字符、160 个 AST 节点、32 层，指数绝对值最多 1000，结果绝对值不超过 1e308；数字宽度上限见「显示精度与继续计算」（整数 16 位、小数 4 位，超出报「数字宽度超限」）。只接受数字与单位结果；数组、矩阵、属性访问、赋值节点、导入、用户函数等均在执行前拒绝。
