# 首版产品规格

状态：有效 · 负责人：项目维护者 · 核验日期：2026-09-07

## 产品目的

在一个安静的桌面窗口中记录想法、预算和算式。用户可以回到原文修改条件、理解结果来源，也可以随手用数字键盘计算，再把算式留下来。

当前假设：macOS 首先落地；中文界面；单人、单窗口、离线本地使用。这些是可调整的启动决策。

## 必须可用的工作流

1. **边写边算**：首次打开有可编辑示例；文字与算式混写，结果按行对应。修改 `交通 = 186 × 2` 为 `交通 = 200 × 2`，预算从 1452 变为 1480、人均含备用金从 798.6 变为 814。
2. **保留思路**：创建、命名、编辑和搜索多篇笔记；刷新或重新打开后恢复内容、当前笔记和主题；读取失败必须保留原数据；移到废纸篓后可以恢复。

   **启动恢复（1.6.0 起）**

   | 上次退出时的状态 | 重开后显示 |
   | --- | --- |
   | 有效笔记 | 该笔记 |
   | 随手算 / 废纸篓视图 / 笔记已不存在（外部删除等）/ 首次打开 | 一篇新的随手算 |

   **侧栏与右键菜单**

   - 侧栏笔记名右键菜单：定位（Finder 显示所在文件）、导出（另存为）、删除（到废纸篓）。
   - 废纸篓里可永久删除：标题旁垃圾桶清空全部、笔记工具里的删除图标删单篇——均带确认弹窗，物理删除对应 .txt 文件；编辑器工具行的「移到废纸篓」也带确认弹窗（1.4.4 起）。

   **编辑历史**

   - 以 `history/<笔记名>/<年-月-日-时-分-秒>.txt` 留档：有实质编辑后每 10 分钟、切换笔记、关闭应用与破坏性操作前各留一份（格式化、一次性剪切/删除 5 行以上；仅空行空格的空文件不留档）。
   - 超过一小时的部分按小时整理为一份整点快照；单篇历史空间上限在设置弹窗配置（KB，默认 128，0 = 关闭且不会立即清空——编辑到哪篇清哪篇、重启应用时清空全部，重启前可反悔），超出淘汰最早、最新一份永不淘汰，启动扫描时清理孤儿历史目录。
   - 历史弹窗（笔记工具行 calendar-clock）可预览并恢复，恢复前当前内容先留档，内容未变不重复备份；每条历史可单独删除（带确认弹窗，1.4.4 起）。


3. **常规计算**：按钮与键盘都可输入数字、小数、四则、括号、百分比；支持 AC、退格、正负切换、等号与最近历史。`200 + 10% =` 得到 220。% 规则（1.6.19 起）：算式里只有一个 %数字、位于末尾且左侧是 +或- 时按紧邻的左操作数计算（`100 + 200 + 10%` = 320，格式化展开为 `100 + 200 + [200 × (10%)]`）；多于一个 %数字、不在末尾或左侧是 ×÷ 时等同小数（`10% + 10%` = 0.2、`100 × 10%` = 10）；`200 + 10‰ =` 得到 202（千分号同族，计算器 % 键显示 `%|‰` 可切换）。计算器子窗口（1.5.5 起）窗口有焦点时键盘整体接管；算式框只读不可聚焦，窗口内不进入中文输入；等号后算式框与结果列同变四位精度的结果值。

   **键盘映射（1.5.5 起）**

   | 输入 | 行为 |
   | --- | --- |
   | 回车 / `=` | 等于 |
   | `C` / `c` / Escape | 清空 |
   | `x` / `X` / `*`、`/` / `\` / `÷` | 乘号、除号（显示 `×` `÷`） |
   | 数字、`.`、`+`、`-`、`%`、括号、Backspace | 直取 |
   | 其余按键 | 忽略无反应（Tab/空格拦下不挪焦点；Cmd/Ctrl/Alt 留给系统） |

   **输入容错（1.6.12 起防范、1.6.13 起自动修正）**

   | 输入场景 | 行为 |
   | --- | --- |
   | `8(` 开括号跟在数字/`%`/关括号后 | 自动补乘号 → `8×(` |
   | `)8` 数字跟在关括号后 | 无反应 |
   | 无未闭合开括号时按 `)`、`)` 紧跟 `(` 或运算符 | 无反应 |
   | 运算符连续输入 | 末尾被新运算符替换（`+` 再 `-` 只留 `-`） |
   | 连续小数点 / 连续百分号 | 只留一个 |
   | `%` 单独或跟在运算符/关括号后 | 无反应 |
   | 第 4 层开括号（括号最多 3 层） | 无反应 |
   | 数字到 16 位整数 / 4 位小数后继续输入 | 无反应（1.6.11 起） |

   **等号容错（1.6.13 / 1.6.14 / 1.6.15 起）**

   | 场景 | 行为 |
   | --- | --- |
   | 有未闭合的开括号 | 自动补齐关括号再算（历史存补整后的算式） |
   | 末尾有悬挂运算符 | 先剥掉再算（`2+` = → 2） |
   | 无效括号：括号里只有纯数字（`2×(8)`、`2×((8))`） | 等号时逐层删除再算，历史存删除后的算式（1.6.15 起；`(50%)`、`(-8)` 保留） |
   | 补整后仍是错误表达式 | 显示错误，不出现数值 |
   | 算式框/续算基值/历史条目 | 不带千分位逗号；结果大字仍带（1.6.14 起） |

   括号按嵌套自动换形 `{[( )]}`——最内层 `()`，向外 `[]`、`{}`（输入 `((8 + 2) × 3) × 4` 显示为 `[(8+2)×3]×4`，与全文格式化同一约定）。


4. **连接两个入口**：点击「写入当前笔记」，计算器算式按格式化设置整理该行后插到当前行之后（1.6.16 起），结果由同一内核重算。
5. **带走数据**：侧栏笔记名右键「导出」为 txt——导出与保存同构，算式行都带 `= 结果`（`(18 + 24) × 3` 导出为 `(18 + 24) × 3 = 126`，`sum` 导出为 `sum = 40`），行内注释保留在行尾（`5 × 2 = 10 //棒冰`）。编辑器工具行的导入/导出按钮已移除（1.2.0），笔记本身始终是可直接带走的 `.txt`。
6. **纯文本文件**：桌面版的每篇笔记是数据目录下一个以标题命名的 `.txt`——标题即文件名主干，标题输入框编辑的就是文件名（改名撞名时自动加序号）；正文首行的 `#` 标记只是内容小节，不参与标题。保存时在成功计算的行尾追加 ` = 结果`，导入时剥离并重算：`年龄 = 2025 - 1976 = 49` 读进来是 `年龄 = 2025 - 1976`，重算仍得 49。用户自己放进目录的 `.txt` 不会被删除或改写。
7. **格式化**：设置弹窗配置空格、千分位（拆「笔记千分位逗号」与「结果千分位逗号」两部分，前者格式化时写入正文、后者只影响结果列显示且立即生效）、单位使用（自由/中文/英文大写/英文小写）与单位制（自由/公制/英制/市制）；顶栏「格式化」按设置整理当前笔记全部算式，强制收敛连续空格并去除行尾空格，不改动结果列。默认不自动格式化。结果列的数字与单位间空格实时对齐设置（正文经格式化对齐同一设置，1.4.6），写入 .txt 的结果保持带空格原格式。
8. **轻量使用**：笔记列表可收起；窄窗口保持编辑可用。

   **计算器子窗口**

   - 独立浮动子窗口：单实例，宽高固定（窄态 300×500，展开最近计算 600×500，主体面积不变、无滚动条），顶部 40 px 拖拽区可移动窗口，「历史」按钮右齐锚定在主体列、展开侧栏时不移动；不允许最大化，最小化后从主窗点击可还原。
   - 关闭后重开恢复算式与历史（app 退出即全新），失焦 5 分钟自动收起；主窗「计算器」按钮在子窗口开着时高亮绿；窗口配色始终与主窗一致。
   - 历史项 hover 出现笔形图标可把该条算式插入笔记；数字按钮不让输入框反复失焦。

   **随手算（1.5.6 起）**

   - 顶栏「随手算」按钮打开一篇内存里的临时算稿：不落盘、不进工作区，app 退出即消失；只有该按钮能打开它，App 运行期间切走再点即恢复。
   - 再点普通笔记、新建笔记或「我的笔记」「废纸篓」tab 都会离开随手算（1.6.4 起点当前已激活的 tab 同样离开，且随手算打开期间两个 tab 高亮熄灭）。
   - 没有历史（弹窗永远为空）、不能进废纸篓；其余能力（计算、查找替换、格式化、复制、计算器写入）与普通笔记一致，留存靠用户手动复制全文。


9. **按习惯配置**：设置弹窗提供文件存放位置、编辑历史（每笔记历史空间，见第 2 条）、格式设置（空格与数字、单位写法、单位制，见第 7 条）与关于信息；弹窗最高 565 px，超出部分在内部滚动。侧栏设置行最右侧以太阳/月亮图标在纸白/午夜两套配色间切换，立即应用并保存；About 展示版本、真实构建时间和 GitHub 链接。
10. **选择文件位置**：桌面默认 `~/.calcbook`，选择目录后复制现有笔记并将之后的保存写到该处，重启仍使用所选目录。原文件保留；目标已含不同笔记时明确拒绝覆盖。

## 明确的边界

- 计算语言见 [精确契约](calculation-language.md)，不是任意自然语言。
- 变量只在当前笔记自上而下生效，不跨笔记；错误不会默默产生 0，也不会继续使用失败重定义前的旧值。
- 货币仅支持 CNY/USD/EUR/GBP 的同币种计算，不联网获取汇率。
- 笔记最多 100 篇（含废纸篓），标题 120 UTF-16 字符，正文 100,000 UTF-16 字符；单行算式上限更小。
- 计算器的「最近计算」侧栏以可滚动列表展示历史（无滚动条），内存保留最多 20 条不同算式；关闭、重新打开和切换展示方式仍保留，重启后清空。等号后重复按等号不重复运算。
- 数字宽度上限（1.6.10 起）：用于运算的数字与结果都是整数部分最长 16 位、小数部分最长 4 位，不使用科学计数法。写下的数字超宽报「数字宽度超限」；计算结果超宽报「计算结果数字宽度超限」（1.6.11 起区分文案）；计算器输入到上限后继续按数字无反应（1.6.11 起）。
- 括号嵌套最多 3 层（1.6.12 起）：笔记里超出在结果位置报「括号嵌套层数越限」，计算器输入第 4 层开括号按不进；形态约定 `{[( )]}` 见计算语言契约。
- 计算器文字自动缩小并禁止横向滚动；续算与历史复用使用与显示一致的四位值（1.5.5 起），算式框/续算基值/历史条目不带千分位逗号（1.6.14 起），笔记正文不受影响，详见语言契约。
- 网页预览使用浏览器存储；选择本机目录仅桌面版可用。目录配置与工作区文件分开保存。
- 纯文本导出保留源文，不把结果写成另一份易失真的真相。导入不修改原始文件。
- 行尾 ` = 结果` 是本应用的保存约定，计算语义以本仓库契约为准：外部笔记里个别单位写法（如 `240片`）会报「尚未定义」，见[技术债务](../exec-plans/tech-debt.md)。
