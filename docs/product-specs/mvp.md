# 首版产品规格

状态：有效 · 负责人：项目维护者 · 核验日期：2026-09-07

## 产品目的

在一个安静的桌面窗口中记录想法、预算和算式。用户可以回到原文修改条件、理解结果来源，也可以随手用数字键盘计算，再把算式留下来。

当前假设：macOS 首先落地；中文界面；单人、单窗口、离线本地使用。这些是可调整的启动决策。

## 必须可用的工作流

1. **边写边算**：首次打开有可编辑示例；文字与算式混写，结果按行对应。修改 `交通 = 186 × 2` 为 `交通 = 200 × 2`，预算从 1452 变为 1480、人均含备用金从 798.6 变为 814。
2. **保留思路**：创建、命名、编辑和搜索多篇笔记；刷新或重新打开后恢复内容、当前笔记和主题。读取失败必须保留原数据。移到废纸篓后可以恢复。侧栏笔记名右键菜单：定位（Finder 显示所在文件）、导出（另存为）、删除（到废纸篓）。废纸篓里可永久删除：标题旁垃圾桶清空全部、笔记工具里的删除图标删单篇——均带确认弹窗，物理删除对应 .txt 文件。
3. **常规计算**：按钮与键盘都可输入数字、小数、四则、括号、百分比；支持 AC、退格、正负切换、等号与最近历史。`200 + 10% =` 得到 220。
4. **连接两个入口**：点击「写入当前笔记」，把计算器原算式插到当前行之后，结果由同一内核重算。
5. **带走数据**：导入 UTF-8 txt/md/numi 文本，作为一篇新笔记；导出当前笔记为 txt——导出与保存同构，算式行都带 `= 结果`（`(18 + 24) × 3` 导出为 `(18 + 24) × 3 = 126`，`sum` 导出为 `sum = 40`），行内注释保留在行尾（`5 × 2 = 10 //棒冰`）。原生导入导出使用系统对话框。
6. **与 Numi 共用文件**：桌面版的每篇笔记是数据目录下一个以标题命名的 `.txt`。保存时在成功计算的行尾追加 ` = 结果`，导入时剥离并重算：Numi 文件里的 `年龄 = 2025 - 1976 = 49` 读进来是 `年龄 = 2025 - 1976`，重算仍得 49；Calcbook 保存的文件也能直接用 Numi 打开。改标题同步改文件名；用户自己放进目录的 `.txt` 不会被删除或改写。
7. **格式化**：设置弹窗的「格式」区配置空格、千分位、单位使用（自由/中文/英文大写/英文小写）与单位制（自由/公制/英制/市制）；顶栏「格式化」按设置整理当前笔记全部算式，强制收敛连续空格并去除行尾空格。默认不自动格式化。
8. **轻量使用**：笔记列表可收起；普通计算器是独立浮动子窗口——单实例，宽高固定（窄态 300×540，展开最近计算 500×540，主体面积不变、无滚动条），不允许最大化，最小化后从主窗点击可还原；关闭后重开恢复算式与历史（app 退出即全新），失焦 5 分钟自动收起；主窗「计算器」按钮在子窗口开着时高亮绿；窗口配色始终与主窗一致；历史项 hover 出现笔形图标可把该条算式插入笔记；数字按钮不让输入框反复失焦。窄窗口保持编辑可用。
9. **按习惯配置**：设置弹窗提供文件存放位置、格式设置（空格与数字、单位写法、单位制，见第 7 条）与关于信息；弹窗最高 565 px，超出部分在内部滚动。侧栏设置行最右侧以太阳/月亮图标在纸白/午夜两套配色间切换，立即应用并保存；About 展示版本、真实构建时间和 GitHub 链接。
10. **选择文件位置**：桌面默认 `~/.calcbook`，选择目录后复制现有笔记并将之后的保存写到该处，重启仍使用所选目录。原文件保留；目标已含不同笔记时明确拒绝覆盖。

## 明确的边界

- 计算语言见 [精确契约](calculation-language.md)，不是任意自然语言或 Numi 全语法复制。
- 变量只在当前笔记自上而下生效，不跨笔记；错误不会默默产生 0，也不会继续使用失败重定义前的旧值。
- 货币仅支持 CNY/USD/EUR/GBP 的同币种计算，不联网获取汇率。
- 笔记最多 100 篇（含废纸篓），标题 120 UTF-16 字符，正文 100,000 UTF-16 字符；单行算式上限更小。
- 计算器显示最近 4 条，内存保留最多 20 条不同算式；关闭、重新打开和切换展示方式仍保留，重启后清空。等号后重复按等号不重复运算。
- 计算器结果最多三位小数、十位整数；更大的数使用科学计数法。文字自动缩小并禁止横向滚动；历史/续算使用未按显示规则舍入的原值，详见语言契约。
- 网页预览使用浏览器存储；选择本机目录仅桌面版可用。目录配置与工作区文件分开保存。
- 纯文本导出保留源文，不把结果写成另一份易失真的真相。导入不修改原始文件。
- 行尾 ` = 结果` 采用 Numi 的约定，但计算语义仍是本仓库契约的子集：Numi 认可的 `片`、`毫克` 等写法在 Calcbook 里可能报错，结果的小数位与千分位显示也不完全一致，见[技术债务](../exec-plans/tech-debt.md)。
