# 界面与交互规范

状态：有效 · 负责人：项目维护者 · 核验日期：2026-09-07

## 方向

Numi 的“左边思路、右边答案”是交互参照；Calcbook 默认采用独立的纸白与苔绿视觉，提供纸白与午夜两套配色。主体是实际工作区，不使用营销首页、指标卡片墙或复杂工具栏。

三列：234 px 笔记导航、弹性编辑区域、290 px 普通计算器。窄于 1150 px 时计算器作为可收起浮层；窄于 760 px 时导航为抽屉。用户可以收起两侧专注写作。

选择弹窗模式时，计算器以 328 px 宽的居中 dialog 打开，不占用工作区列；小窗口限制为视口宽度减 32 px。点击计算器外部任意位置或 Escape 关闭，并恢复原焦点。重新打开仍保留会话内的算式和历史。

## 窗口与标题栏

桌面版使用 macOS Overlay 标题栏并隐藏原生标题：内容延伸到标题栏区域，主列顶栏（面包屑、保存状态、计算器开关）即标题行，与侧栏品牌行同为 `data-tauri-drag-region` 拖拽区。由于该属性只对标记元素本身生效，平台层在桌面版额外安装 mousedown 处理器：按住区域内任意非交互内容（面包屑文字、字标、空白处）即可拖动窗口；按钮、输入框等交互元素不受影响。浏览器预览没有该处理器，布局不变。`document.title` 仍提供窗口标题供 Mission Control 等系统界面使用。

## 视觉事实来源

配色统一在 [theme.css](../../src/theme.css)，布局在 [styles.css](../../src/styles.css)。本机系统字体用于 UI，系统等宽字体用于算式；无需在线加载字体。强调色表达可计算内容与结果，错误同时有图标和文字。

保持轻边框、少量圆角、克制阴影与稳定悬停。按键区使用熟悉的四列布局，等号为主强调。图标统一使用 Lucide；字标与应用 SVG 为项目原创。

## 设置与主题

左下角设置行以设置图标进入设置；同一行最右侧是太阳/月亮切换按钮，浅色显示月亮（切换到深色），深色显示太阳（切换到浅色）。`⌘/Ctrl ,` 也可打开设置。设置使用原生 modal dialog，包含存储位置、计算器模式、关于信息；改动立即应用并按真实保存状态反馈。

| 配色 | 标识 | 明暗 |
| --- | --- | --- |
| 纸白 | paper | 浅色 |
| 午夜 | midnight | 深色 |

切换按钮是有可访问名称的图标按钮，切换立即生效并写入工作区。旧版六套主题在读取时迁移：`light`/`sand`/`mist` 为 `paper`，`dark`/`forest`/`graphite` 为 `midnight`；未知主题仍报错。设置弹窗不再包含主题配色块。About 展示 app 版本、编译时注入的构建时间与可打开的 GitHub 链接。浏览器预览的文件夹按钮禁用并说明实际存储位置；不能显示虚假的文件保存成功。

目录切换期间禁用重复选择和设置关闭，先完成待保存写入，再复制文件、提交新位置；取消系统对话框保持原设置。失败原因显示在设置内部。

## 计算器输入与显示

鼠标按下数字键时阻止按钮抢焦点；仅首次需要继续输入时聚焦算式框。键盘 Tab 仍可进入按键，Enter/Space 激活后保留按钮焦点。结果最多三位小数与十位整数，超过上限使用科学计数法；按文字实际宽度缩小字号，禁止横向滚动，不裁切负号。

## 编辑器

原生 textarea 保留选择、粘贴、撤销与中文输入法；其下的无交互文本镜像只承担着色。源文本与结果固定 34 px 行高并处于同一滚动区域，不允许结果和行错位。长行水平滚动而非折行，避免一行对应多个高度。

结果是有可访问名称的复制按钮。行级错误可通过鼠标悬停或键盘聚焦查看。辅助镜像不进入可访问树，读屏只读取真实文本与结果。

## 必须检查

- 主界面的新建、搜索、编辑、复制、导入导出、废纸篓恢复与计算器都需要真实行为。
- 普通计算器仅在自己的输入框内接管 Enter/Escape；不能抢走编辑器的数字键或输入法事件。
- 所有图标按钮具有 title 与 aria-label；焦点可见；帮助、设置和计算器弹窗共用原生 modal dialog。
- 明暗主题都可读；主文本与次要说明保证对比度，装饰性行号不承载独立含义。
- 尊重 prefers-reduced-motion。检查 375、768、1280 和 1440 px 宽度；不能产生页面水平溢出。
- 自动保存反馈必须真实；出错不能用成功 toast 掩盖。

当前 textarea 镜像是有意的轻实现。语法补全、多光标、超长文档虚拟化出现真实需求时再评估编辑器库，见 [技术债务](../exec-plans/tech-debt.md)。
