# 界面与交互规范

状态：有效 · 负责人：项目维护者 · 核验日期：2026-09-07

## 方向

Numi 的“左边思路、右边答案”是交互参照；Calcbook 默认采用独立的纸白与苔绿视觉，提供纸白与午夜两套配色。主体是实际工作区，不使用营销首页、指标卡片墙或复杂工具栏。

两列：260 px 笔记导航、弹性编辑区域。普通计算器是独立的浮动子窗口。顶栏放「格式」「格式化」两个按钮（保存失败时原位显示「尚未保存」）；「格式」打开格式设置弹窗（括号与数字间空格为强制规则不可配置），「格式化」按设置整理当前笔记。窄于 760 px 时导航为顶栏下方的抽屉。

收起/展开笔记列表的按钮常驻在顶栏面包屑最左侧（「我的笔记」左边），随状态切换收起/展开图标并同步 `aria-expanded`。侧栏通过自身宽度 220 ms 过渡平滑收放（grid auto 列跟随），收起完成后 `visibility: hidden` 移出 Tab 序；窄窗口抽屉用 `translateX` 滑入滑出，遮罩点击关闭。动画尊重 prefers-reduced-motion。侧栏内笔记列表使用 3 px 极细滚动条，画在右侧留白区不压缩卡片，静止时隐藏、悬停列表时出现。

## 计算器子窗口

普通计算器是主窗口之外的一个浮动子窗口，由 Rust 按需创建（label `calculator`，加载同一前端包的 `?view=calculator` 路由）。

- **单实例**：重复点击「计算器」不会开第二个窗口；已最小化时点击会还原并聚焦，已打开时仅聚焦。
- **窗口形态**：与主窗同为 Overlay 标题栏（红绿灯保留、标题文字隐藏，顶部 38 px 拖拽区，每次打开都重新居中到主窗口正中间）。宽高固定，窄态 300×540，展开「最近计算」侧栏后 600×540——计算器主体固定 300 px 面积不变，侧栏 300 px；不允许最大化（macOS 绿点 zoom 禁用），用户不能手动 resize，窗口无滚动条。
- **关闭语义**：红绿灯「关闭」由 Rust 转为隐藏，算式与历史保留；从主窗再次打开即恢复。app 退出后进程结束，再打开是全新状态。主窗口销毁时计算器一并销毁。
- **自动收起**：失焦（含最小化）5 分钟未被再次激活，前端调用 Rust 隐藏窗口。
- **主窗按钮**：子窗口开着（不论是否最小化）时「计算器」按钮高亮绿，由 Rust 在显示/隐藏时推送 `calculator://visible` 事件驱动；未打开为普通颜色。浏览器预览点击提示仅桌面版可用。
- **写入当前笔记**：子窗口通过 `calculator://insert` 事件把原算式发给主窗，由主窗插入当前行之后，主窗显示「算式已写入笔记」。
- **最近计算**：「历史」按钮（书本图标 + 文字）紧跟红绿灯左对齐，切换显示/隐藏侧栏；侧栏 200 px，内容可滚轮滚动但不显示滚动条。历史项 hover 时右侧出现笔形图标，点击把该条算式插入主窗笔记；点击条目其余部分仍是用结果续算。没有「写入当前笔记」按钮。
- **主题**：与主窗始终一致——桌面版启动时由主窗在子窗打开瞬间推送当前配色（工作区主题存在文件系统而非 localStorage），主窗切换纸白/午夜时经 `calculator://theme` 事件同步；浏览器预览读 localStorage。

## 窗口与标题栏

桌面版使用 macOS Overlay 标题栏并隐藏原生标题：内容延伸到标题栏区域，主列顶栏（面包屑、保存状态、计算器开关）即标题行，与侧栏品牌行同为 `data-tauri-drag-region` 拖拽区。侧栏内容从红绿灯下方 46 px 处开始，字标左对齐、不再横向避让交通灯；仅侧栏收起时顶栏左侧保留 84 px 让位红绿灯。由于该属性只对标记元素本身生效，平台层在桌面版额外安装 mousedown 处理器：按住区域内任意非交互内容（面包屑文字、字标、空白处）即可拖动窗口；按钮、输入框等交互元素不受影响。浏览器预览没有该处理器，布局不变。`document.title` 仍提供窗口标题供 Mission Control 等系统界面使用。

## 视觉事实来源

配色统一在 [theme.css](../../src/theme.css)，布局在 [styles.css](../../src/styles.css)。本机系统字体用于 UI，系统等宽字体用于算式；无需在线加载字体。强调色表达可计算内容与结果，错误同时有图标和文字。

保持轻边框、少量圆角、克制阴影与稳定悬停。按键区使用熟悉的四列布局，等号为主强调。图标统一使用 Lucide；字标与应用 SVG 为项目原创。

## 设置与主题

左下角设置行以设置图标进入设置；同一行最右侧是太阳/月亮切换按钮，浅色显示月亮（切换到深色），深色显示太阳（切换到浅色）。`⌘/Ctrl ,` 也可打开设置。设置使用原生 modal dialog，包含单位写法、存储位置与关于信息；改动立即应用并按真实保存状态反馈。计算器模式设置已移除（只保留边栏形态），旧工作区中的 calculatorMode 字段读取时忽略。

单位写法是三选一的原生 radio 组（自由单位/中文单位/英文单位，默认自由），选择立即写入工作区。中文/英文模式下，光标离开刚算完的一行（行序变化或编辑器失焦）时，该行算式里的单位自动改写成对应语言（`100L` → `100升`，`4毫升` → `4 ml`）；自由模式只在该行中英文单位混用时统一成中文。改写只处理这一行，标签与 `//` 注释不动，选择文本（非折叠光标）时不触发。

| 配色 | 标识 | 明暗 |
| --- | --- | --- |
| 纸白 | paper | 浅色 |
| 午夜 | midnight | 深色 |

切换按钮是有可访问名称的图标按钮，切换立即生效并写入工作区。旧版六套主题在读取时迁移：`light`/`sand`/`mist` 为 `paper`，`dark`/`forest`/`graphite` 为 `midnight`；未知主题仍报错。设置弹窗不再包含主题配色块。About 展示 app 版本、编译时注入的构建时间与可打开的 GitHub 链接。浏览器预览的文件夹按钮禁用并说明实际存储位置；不能显示虚假的文件保存成功。

目录切换期间禁用重复选择和设置关闭，先完成待保存写入，再复制文件、提交新位置；取消系统对话框保持原设置。失败原因显示在设置内部。

## 注释渲染

`#` 与 `//` 作用一致：整行与尾部注释都用注释颜色渲染，计算结果只在右侧结果区；保存文件时尾部注释保留在行尾、结果写在算式之后（`5 kg = 36 # 备注`）。

## 聚焦反馈

搜索框与计算器算式输入不显示描边型 focus ring；聚焦状态用所属容器的背景色变化表达（搜索框整体、计算器屏幕区），并保留边框颜色变化。三个输入区（搜索框、计算器算式、编辑器）的文本光标使用纯黑（纸白）/纯白（午夜）以获得最高对比；光标粗细由浏览器决定，不可配置。其他控件的键盘 focus ring 保持可见。

## 计算器输入与显示

鼠标按下数字键时阻止按钮抢焦点；仅首次需要继续输入时聚焦算式框。键盘 Tab 仍可进入按键，Enter/Space 激活后保留按钮焦点。结果最多三位小数与十位整数，超过上限使用科学计数法；按文字实际宽度缩小字号，禁止横向滚动，不裁切负号。

## 语法速查

语法速查弹窗按 tab 分组：「示例」（可点击写入笔记的例子）、「函数与常量」、「汇总与变量」、「关键字」、「单位与符号」——后四个是保留字参考表，写法/作用/例子三列，内容与 [计算语言契约](../product-specs/calculation-language.md) 一致。tab 使用原生 tablist 语义，方向键左右切换，焦点可见；表格文字在明暗主题下都保证对比度。

## 编辑器

原生 textarea 保留选择、粘贴、撤销与中文输入法；其下的无交互文本镜像只承担着色。源文本与结果固定 34 px 行高并处于同一滚动区域，不允许结果和行错位。长行水平滚动而非折行，避免一行对应多个高度。

结果是有可访问名称的复制按钮。行级错误可通过鼠标悬停或键盘聚焦查看。辅助镜像不进入可访问树，读屏只读取真实文本与结果。

## 必须检查

- 主界面的新建、搜索、编辑、复制、导入导出、废纸篓恢复与计算器都需要真实行为。
- 普通计算器仅在自己的输入框内接管 Enter/Escape；不能抢走编辑器的数字键或输入法事件。
- 所有图标按钮具有 title 与 aria-label；焦点可见；帮助与设置弹窗共用原生 modal dialog。
- 明暗主题都可读；主文本与次要说明保证对比度，装饰性行号不承载独立含义。
- 尊重 prefers-reduced-motion。检查 375、768、1280 和 1440 px 宽度；不能产生页面水平溢出。
- 自动保存反馈必须真实；出错不能用成功 toast 掩盖。

当前 textarea 镜像是有意的轻实现。语法补全、多光标、超长文档虚拟化出现真实需求时再评估编辑器库，见 [技术债务](../exec-plans/tech-debt.md)。
