## Numi 的产品骨架

Numi 把计算嵌入可持续编辑的文本。左侧是文本/表达式，右侧是与行对齐的结果；标题、说明、变量和算式在同一块编辑区域内共存。数值变化后，上下文中的计算随之更新。

| 官方能力 | 文档中的具体例子 | 本项目处理 |
| --- | --- | --- |
| 文字与表达式共存 | `# This is header`、`Price: $11 + $34.45` | 首版保留标题、注释、标签 |
| 算术和文字运算符 | `8 times 9`、`6 (3)` | 首版支持常用子集 |
| 变量 | `v = $20`，后续行引用 | 首版支持中文与英文变量 |
| 百分比 | `$10 - 40%`、`20% of $10` | 首版支持相对百分比、of/on/off |
| 上一结果、汇总 | `prev`、`sum`、`average` | 首版支持；空行划分汇总段落 |
| 单位 | 长度、重量、数据、温度、时间等 | 首版使用 mathjs 的常用单位与转换 |
| 货币/加密货币 | 在线汇率，定时更新 | 首版仅同币种金额，跨币种明确报错 |
| 时区与日期 | `Time in Madrid` 等 | 延后；时间长度换算已支持 |
| 科学函数、进制和位运算 | 三角函数、root、log、hex 等 | 先做 sqrt/abs/round/ceil/floor |
| 纯文本导入导出 | UTF-8 `.numi` 文件 | 导入 txt/md/numi；导出 txt，语法不承诺全兼容 |
| 工作流与扩展 | Alfred、CLI、JavaScript plugins | 延后 |

## 视觉与交互观察

官网展示的是小型、克制的桌面窗口：文本编辑区域占主体，结果右对齐，语法与结果使用少量强调色，同时展示明暗主题。展示中没有常规数字键盘作为主体。

Calcbook 因为还承担“笔记本”和普通计算器，采用可收起的笔记列表 + 文本工作区 + 可收起计算器。保持逐行结果的核心关系，使用独立的纸白/苔绿配色、图标和字标；不复制 Numi 素材。

## Harness 原文怎样用于这个仓库

| 原文经验 | 对应实现 | 暂不照搬的部分 |
| --- | --- | --- |
| AGENTS 是地图，不是百科全书 | 简短入口 + 有索引的 docs | 巨型一体化指令文件 |
| 仓库是真相来源 | 产品契约、设计依据、计划、债务、质量证据纳入 Git | 外部聊天作为唯一决策记录 |
| 架构通过机器约束 | AST import 检查、纯计算域、存储边界 | 百万行项目的六层架构 |
| 给智能体可读反馈 | 浏览器预览、可访问名称、原生错误、可复现测试 | 集群日志/指标平台 |
| 把反馈变成规则 | 回归用例、坏数据测试、文档链接检查 | 不经判断自动增加工具 |
| 环境隔离 | 每个 checkout 的开发数据、可配置端口 | 当前不需要的容器编排 |
| 持续消除漂移 | 每次变更更新相关文档，人工触发检查 | 未请求的定时自动任务 |

文章里的代码规模、无人手写约束和吞吐量是其内部实验背景，不能作为 Calcbook 的质量或性能承诺。这里采用的是可验证的工作方法。
