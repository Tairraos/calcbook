# 0001 · Harness 与可运行首版

状态：验收中 · 负责人：项目维护者 · 核验日期：2026-09-07

## 目标

从空仓库启动可持续由智能体维护的 Tauri 2 计算笔记本，交付 Numi 风格的行内计算与普通计算器，而非仅建立文档目录。

## 验收

- [x] 阅读 OpenAI harness engineering 原文与 Numi 官方资料，记录来源与适用取舍。
- [x] 建立简短 AGENTS 地图、产品契约、架构、设计、执行计划和质量证据。
- [x] Tauri 桌面与浏览器预览均可启动；两个输入入口共用计算内核。
- [x] 覆盖四则运算、变量、百分比、单位转换、分段汇总与错误隔离。
- [ ] 笔记创建、编辑、搜索、删除撤销、保存恢复、纯文本导入导出可用。
- [x] 普通计算器支持鼠标、键盘、历史和插入笔记。
- [ ] 自动检查能阻止架构越界、文档断链、错误计算与持久化回归。
- [ ] 实际操作 UI，记录检查结果、限制与后续路线，归档此计划。
- [ ] 设置弹窗：默认 ~/.calcbook、原生目录选择与旧数据迁移、明暗切换（纸白/午夜两套配色）、计算器边栏/弹窗、版本/构建时间/GitHub。
- [x] 修复计算器焦点闪动；三位小数、十位整数显示上限与字号适配，续算保留内部精度。
- [x] 笔记支持 x 乘法和三种括号；移除侧栏离线文案与月亮按钮。

## 决策

2026-09-06：macOS 优先、中文界面、离线本地数据；Tauri 2 + React + TypeScript + Vite。

2026-09-06：用 mathjs 的十进制数、单位与受限 AST 执行，避免重新实现数学解析器；仅增加 Numi 风格的逐行语义。

2026-09-06：首版采用原生 JSON 原子替换保存与浏览器 localStorage 预览，不引入数据库、同步服务、全局状态库或编辑器框架。

2026-09-06：文章中的“地图、仓库事实、可执行约束、反馈闭环”立即落地；不照搬百万行项目的多层架构和遥测基础设施。
